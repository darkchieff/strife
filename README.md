# Vendetta Plugins
This repo contains [Vendetta](https://github.com/vendetta-mod/Vendetta) plugins.

# How to install?
Paste a plugin URL into the Plugins page of your client mod, following a basic format of:

https://darkchieff.github.io/strife/PLUGIN_NAME/

For example, Experiments:

https://darkchieff.github.io/strife/Experiments/
